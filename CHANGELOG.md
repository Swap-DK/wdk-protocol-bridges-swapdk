## 2026-04-27 — Monorepo bootstrap

Pre-publish consolidation of the EVM and Solana protocol packages, originally developed in separate repositories, into this monorepo.

- Set up npm workspaces over `packages/*`.
- Added shared `tsconfig.base.json`, root `LICENSE`, `.editorconfig`, `.gitignore`.
- Initialised changesets for independent per-package versioning.
- Migration plan: `packages/evm/` and `packages/solana/` will land verbatim from their source repos in the next commits, then `packages/common/` will be extracted file-by-file with tests staying green at each step.
